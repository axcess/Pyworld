API cheat sheet
def tick(drone):            # runs for every drone, every tick
  drone.x, drone.y, drone.cargo, drone.capacity, drone.id
  drone.memory               # dict that persists for this drone
  drone.at_base()   drone.ore_here()
  drone.move(dx, dy)         # one step, no diagonals
  drone.move_toward(x, y)
  drone.mine()  drone.deposit()   # base is at (0, 0)
  drone.scan()               # LOCKED: [(x, y, amount), ...] within 6 tiles

def colony_tick(colony):    # optional, runs once per tick
  colony.ore, colony.drones, colony.tick, colony.memory
  colony.buy_drone()   colony.has("scan")

Rules: 1 action per drone per tick. Each drone gets a CPU budget of traced
lines per tick; blow it and that drone idles. Only `math` can be imported.
